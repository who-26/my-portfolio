01

사용자 시나리오

  1. 방문자메인에서 소개와 스킬, 대표 작업물을 확인하고 관심 있는 작업물의 상세로 이동한다. 실제 결과물을 새 창으로 체험한 후 기존 탐색 위치로 돌아간다.
  2. 방문자Work 목록에서 키워드를 선택해 작업물을 찾고, 상세의 간단 문의 또는 Contact에서 이메일과 프로젝트 내용을 남긴다.
  3. 운영자로그인하여 작업물을 등록·수정·삭제하고 메인 대표 작업물을 지정한다.
  4. 운영자문의 목록과 상세를 확인한다. 문의에는 확인 날짜가 기록되고 보관 기간이 지나면 삭제된다.

메인 소개 및 스킬 표시

필수

기획·운영 PM의 역량과 사이트 성격을 소개하기 위해

어느 화면
메인
무엇을 하면
접속하거나 스킬 영역까지 스크롤하면
무슨 일이

  • 스킬 영역에 도달하면 항목별로 하나씩 떠오르는 효과를 적용한다.
예외 상황
이미지 로딩 실패 시 대체 영역을 표시한다. 동작 줄이기를 설정한 환경에서는 애니메이션 없이 바로 표시한다.

작업물 상세
무엇을 하면

상세 화면 간단 문의

필수

어느 화면
작업물 상세 하단
무엇을 하면
접속 후 1~2초가 지나면
입력값 제약
  • 이메일·요구사항 필수
  • 이메일 최대 254자, 요구사항 최대 2,000자

  • 개인정보 동의와 '접수하기' 버튼을 제공하고 성공 시 '문의가 접수되었습니다' 안내를 표시한다.

필수값 누락·잘못된 이메일·동의 미체크 시 저장하지 않고 해당 항목 입력 알럿 표출. 저장 실패 시 입력 내용을 유지.

Contact 문의 접수

필수

협업 및 프로젝트 문의를 받기 위해

어느 화면
Contact
무엇을 하면
이메일·프로젝트 내용을 입력하고 개인정보 동의 후 전송하면
입력값 제약
  • 이메일 최대 50자, 내용 최대 2,000자, 모두 필수
  • 링크는 내용에 텍스트로 입력
  • 입력값 검증하여 공격 방지 필요
무슨 일이
  • 연락 유도 문구와 입력 폼을 표시한다. 프로젝트 내용에는 링크를 입력할 수 있다.
  • 정상 저장 후 '문의가 접수되었습니다' 안내를 표시한다.
예외 상황
잘못된 이메일·빈 내용·동의 미체크 시 항목별 안내를 표시한다. 저장 실패 시 입력 내용을 유지하고 재시도를 안내한다.

작업물 등록·수정 및 대표 지정

필수

결과물을 등록·관리하기 위해

어느 화면
관리자 작업물 관리 / 등록·수정
무엇을 하면
등록 또는 상세의 수정 버튼을 누르고 내용을 입력해 저장하면
입력값 제약
  • 제목 필수·100자 이하
  • 설명/기획 포인트 각 1,000자 이하

  • 관리자 상세에는 수정·삭제 버튼을 표시한다.
  • 저장 성공 안내 후 상세로 이동한다.
예외 상황
필수값 누락·잘못된 파일·링크는 저장 전에 알럿 표출. 저장 실패 시 입력 내용을 유지한다. 비로그인 접근·저장 요청은 차단한다.

12

운영자 로그인

필수

운영자만 관리 기능을 사용할 수 있도록 하기 위해

어느 화면
관리자 로그인
무엇을 하면
아이디와 비밀번호를 입력하고 로그인 버튼을 누르면
입력값 제약
  • 아이디·비밀번호 필수
  • 운영자 계정만 사용하며 회원가입은 제공하지 않는다.
무슨 일이
  • 인증 성공 시 관리자 화면에 접근할 수 있다. 일반 방문자에게 관리 버튼을 표시하지 않는다.
  • 작업물 관리 화면으로 이동하고 로그아웃 기능을 제공한다.
  • 로그인 유지 세션 시간 30분
예외 상황
인증 실패 시 '아이디 또는 비밀번호를 확인해주세요' 안내를 표시한다. 세션 만료 시 재로그인을 안내한다. 버튼 숨김 외에 서버에서도 조회·변경 권한을 검증한다.
