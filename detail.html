사용자 화면

방문자
U-01

메인

첫인상 · 대표 작업물

  • 진입메인 접속 시 이미지 표출, 0.5~1초 후 키워드 텍스트 표출
  • 스크롤스킬 항목 표출 — 항목별로 하나씩 떠오르는 효과
  • 스크롤대표 작업물 목록 표출 작업물 영역으로 이동하면 'Contact' 플로팅 배너 표출 → 클릭 시 Contact 화면으로 이동
  • 클릭작업물 클릭 시 작업물 상세 화면으로 이동
  • 클릭'더보기' 클릭 시 작업물 목록 화면으로 이동
U-02

작업물 목록

전체 작업물 · 키워드 검색

  • 진입메인의 GNB(Work 메뉴) 또는 '더보기'를 통해 이동
  • 검색키워드 목록에서 키워드 선택
  • 검색선택한 키워드 개별 삭제, 전체 선택 삭제
U-03

작업물 상세

레이어 팝업형 별도 페이지

  • 구성레이어 팝업 형태로 디자인 (실제로는 별도 페이지)
  • 구성제목 → 기획 포인트 → 이미지 순으로 표출
  • 호버이미지에 마우스를 올리면 화살표 표출, 클릭 시 해당 작업물 페이지를 새 창으로 열기
  • 진입접속 1~2초 후 팝업 하단에 간단한 문의 창 표출 이메일, 요구사항 입력
  • 닫기우측 상단 'X' 클릭 시 메인에서 이전에 스크롤했던 위치로 복귀
U-04

Contact

문의 폼

  • 구성간단한 연락 유도 문구 표출
  • 입력이메일 입력
  • 입력같이 하고 싶은 프로젝트 내용 입력 (링크 입력 가능)
  • 입력개인정보 활용 동의 체크
보안: SQL 인젝션 등 입력값을 이용한 공격 방지 필요

관리자 화면

운영자 전용
A-01

작업물 관리

등록 · 수정 · 삭제

  • 등록제목, 이미지, 설명, 링크를 입력해 작업물 추가, 메인에 보일 대표 작업물 여부 지정
  • 상세관리자로 작업물 상세에 접속하면 수정·삭제 버튼 표출
  • 수정수정 클릭 시 수정 화면으로 이동, 저장 시 수정 사항 반영
  • 삭제삭제 클릭 시 확인 알럿 표출, 확인을 누르면 삭제
A-02

문의 내역

방문자 문의 확인

  • 목록방문자 문의 내역 목록 표출
  • 상세클릭 시 문의 상세로 이동해 조회, 확인 시 '확인 날짜' 항목 생성
  • 보관보관 기간이 지나 DB에서 삭제된 문의는 목록에서도 삭제
A-03

로그인

운영자 인증

  • 인증아이디, 비밀번호를 입력해 검증, 운영자만 관리자 화면에 접속 가능
