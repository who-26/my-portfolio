01

사용자 시나리오

  1. 방문자메인에서 소개와 스킬, 대표 작업물을 확인하고 관심 있는 작업물의 상세로 이동한다. 실제 결과물을 새 창으로 체험한 후 기존 탐색 위치로 돌아간다.
  2. 방문자Work 목록에서 키워드를 선택해 작업물을 찾고, 메인의 플로팅 배너·하단 Contact 영역 또는 상세의 이메일 버튼을 눌러 메일 앱으로 문의한다.
  3. 운영자로그인하여 작업물을 등록·수정·삭제하고 메인 대표 작업물을 지정한다.

기능별 상세

사용자 기능 방문자
01

메인 소개 및 스킬 표시

필수

기획·운영 PM의 역량과 사이트 성격을 소개하기 위해

어느 화면
메인
무엇을 하면
접속하거나 스킬 영역까지 스크롤하면
무슨 일이
  • 접속 시 이미지를 먼저 표시하고 0.5~1초 후 키워드 텍스트를 표시한다.
  • 스킬 영역에 도달하면 항목별로 하나씩 떠오르는 효과를 적용한다.
예외 상황
이미지 로딩 실패 시 대체 영역을 표시한다. 동작 줄이기를 설정한 환경에서는 애니메이션 없이 바로 표시한다.
의존관계
소개 이미지·키워드·스킬 콘텐츠 준비
02

대표 작업물 및 이메일 플로팅 배너

필수

대표 결과물과 연락 경로를 쉽게 제공하기 위해

어느 화면
메인
무엇을 하면
작업물 영역까지 스크롤하고, 플로팅 배너에 PC는 마우스를 올리거나 모바일은 탭하면
무슨 일이
  • 대표로 지정한 작업물을 표시한다.
  • 해당 영역에 도달하면 이메일 플로팅 배너를 표시한다.
  • PC: 배너에 마우스를 올리면 펼쳐지며 이메일 주소를 표시하고, 클릭하면 메일 앱을 열어 받는 사람에 운영자 이메일을 미리 채운다.
  • 모바일: 배너를 탭하면 펼쳐지며 이메일 주소를 표시하고, 펼쳐진 주소를 탭하면 메일 앱을 열어 받는 사람에 운영자 이메일을 미리 채운다. 배너 바깥을 탭하면 접힌다.
  • 카드 클릭 시 상세로, 더보기 클릭 시 목록으로 이동한다.
예외 상황
대표 작업물이 없으면 안내 문구를 표시한다. 배너는 모바일에서도 콘텐츠·버튼을 가리지 않도록 배치한다. 메일 앱이 없는 환경에서도 펼쳐진 주소를 보고 옮겨 적을 수 있다.
의존관계
작업물 등록 및 대표 여부 지정, 운영자 이메일 주소 확정
03

작업물 목록 및 키워드 검색

필수

관심 있는 작업물을 키워드로 찾기 위해

어느 화면
작업물 목록
무엇을 하면
GNB의 Works 또는 메인의 더보기로 이동하고 키워드를 선택하면
무슨 일이
  • 전체 작업물을 표시하고 선택한 키워드에 따라 목록을 필터링하는 검색 기능을 제공한다.
  • 선택 키워드를 개별 삭제하거나 전체 해제하면 목록을 갱신한다.
예외 상황
등록 작업물이 없으면 빈 목록 안내를 표시한다. 키워드 검색 결과가 없으면 안내 문구를 제공한다.
의존관계
작업물 데이터 및 키워드 연결. 여러 키워드 선택 시 AND 방식
04

작업물 상세 및 외부 서비스 연결

필수

작업물의 기획 포인트를 소개하고 실제 서비스를 확인하도록 하기 위해

어느 화면
작업물 상세
무엇을 하면
메인 또는 Works 목록의 작업물을 클릭하거나 이미지를 선택하면
무슨 일이
  • 별도 페이지를 레이어 팝업처럼 디자인하고 제목 → 기획 포인트 → 이미지 순으로 표시한다.
  • 이미지 호버 시 화살표를 표시하고 클릭 시 작업물 링크를 새 창으로 연다.
예외 상황
존재하지 않거나 삭제된 작업물은 안내와 목록 이동 버튼을 제공한다. 링크가 없으면 외부 이동을 비활성화한다. 모바일에는 호버 없이도 이동 버튼을 표시한다.
의존관계
작업물 등록, 이미지 및 외부 링크

상세 화면 닫기 및 위치 복귀

필수

작업물 상세
무엇을 하면

  • 목록에서 들어온 경우 선택 키워드와 스크롤 위치를 유지해 목록으로 돌아간다.
예외 상황
주소로 직접 접속해 이전 화면 정보가 없으면 작업물 목록으로 이동한다.

상세 화면 이메일 문의

필수

작업물을 보던 중 간편하게 문의할 수 있도록 하기 위해

어느 화면
작업물 상세 하단

'문의하기' 버튼을 누르면

메인 하단 Contact 영역

필수

메인을 끝까지 본 방문자가 바로 연락할 수 있도록 하기 위해

메인 하단

  • 누르면 메일 앱을 열고 받는 사람에 입력한 이메일을 미리 채운다.
예외 상황
메일 앱이 없는 환경에서도 주소를 옮겨 적을 수 있도록 이메일 주소를 텍스트로 항상 표시한다.

08

작업물 등록·수정 및 대표 지정

필수

결과물을 등록·관리하기 위해

어느 화면
관리자 작업물 관리 / 등록·수정
무엇을 하면
등록 또는 상세의 수정 버튼을 누르고 내용을 입력해 저장하면
입력값 제약
  • 제목 필수·100자 이하
  • 설명/기획 포인트 각 1,000자 이하
  • 이미지 JPG·PNG·WebP, 파일당 5MB 이하
  • 링크는 http/https만 허용
무슨 일이
  • 제목·이미지·설명·링크와 메인 대표 여부를 저장한다.
  • 관리자 상세에는 수정·삭제 버튼을 표시한다.
  • 저장 성공 안내 후 상세로 이동한다.
예외 상황
필수값 누락·잘못된 파일·링크는 저장 전에 알럿 표출. 저장 실패 시 입력 내용을 유지한다. 비로그인 접근·저장 요청은 차단한다.
의존관계
관리자 로그인, 작업물 DB 및 이미지 저장 기능
09

작업물 삭제

필수

필요 없어진 내용을 제거하기 위해

어느 화면
관리자 작업물 상세
무엇을 하면
삭제 버튼을 누르고 확인 창에서 확인하면
무슨 일이
  • 삭제 확인 알럿을 표시하고 확인 시 삭제한다.
  • '삭제되었습니다' 안내 후 관리 목록으로 이동하고 사용자 목록·대표 영역에서도 제외한다.
예외 상황
알럿에서 취소하면 유지한다. 삭제 실패 시 실패를 알럿으로 안내한다. 삭제된 항목에 재접근하면 찾을 수 없다는 안내를 표시한다.
의존관계
관리자 로그인, 삭제 권한 검증
10

운영자 로그인

필수

운영자만 관리 기능을 사용할 수 있도록 하기 위해

어느 화면
관리자 로그인
무엇을 하면
아이디와 비밀번호를 입력하고 로그인 버튼을 누르면
입력값 제약
  • 아이디·비밀번호 필수
  • 운영자 계정만 사용하며 회원가입은 제공하지 않는다.
무슨 일이
  • 인증 성공 시 관리자 화면에 접근할 수 있다. 일반 방문자에게 관리 버튼을 표시하지 않는다.
  • 작업물 관리 화면으로 이동하고 로그아웃 기능을 제공한다.
  • 로그인 유지 세션 시간 30분
예외 상황
인증 실패 시 '아이디 또는 비밀번호를 확인해주세요' 안내를 표시한다. 세션 만료 시 재로그인을 안내한다. 버튼 숨김 외에 서버에서도 조회·변경 권한을 검증한다.
